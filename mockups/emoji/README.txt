Nemino custom emoji pack
========================
29 tiles, 128x128 PNG with a transparent background.

Each file is named after the emoji slot the bot looks for, so uploading
ok.png creates the emoji :ok: and the cards pick it up by name.

Discord has no zip import for server emoji, so unzip and upload the PNGs
(Server Settings > Emoji > Upload Emoji). Keep the file names unchanged.

Slots: ok no warn up down swap ticket app file log gift idea vouch staff
palm clock shield honey broom money trophy note chart list spark gear m1 m2 m3

Every slot falls back to a plain glyph in code if the emoji is missing, so
nothing breaks if you upload only some of them.
